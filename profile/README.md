# MQ-EdTech

We build software that automates and assists teaching and learning in Computer Science at [Macquarie University](https://www.mq.edu.au/).

Our tools support students and staff across the CS curriculum — from automated feedback on programming assignments to citation checking for written work.

## Tools

### [Majordomo](https://github.com/MQ-EdTech/majordomo)

An automated student feedback pipeline. Runs programming submissions through a configurable rule set and returns structured, consistent feedback to students faster than manual marking allows.

*Used in undergraduate CS units. Students and staff can share feedback via the [Majordomo Feedback issue template](https://github.com/MQ-EdTech/.github/issues/new/choose).*

### [Zita](https://github.com/MQ-EdTech/Zita)

Production-grade static code analysis for [Processing](https://processing.org/) sketches. Converts Processing code to Java and applies a custom PMD ruleset designed for educational assessment — catches common issues before students submit.

*Used in introductory CS units that teach Processing.*

### [APA 7 Reference Checker](https://github.com/MQ-EdTech/apa7-reference-checker)

Validates APA 7 references and in-text citations in `.docx`, `.pdf`, and plain-text essays. Helps students self-check their reference lists before submission, and gives staff a baseline tool for citation-style feedback. Open source — engine + CLI today, web/API/LTI integrations planned.

## Getting involved

**Students** — tell us what's working, what's confusing, and what you'd change. Feedback is **anonymous-friendly** (use a GitHub handle that doesn't identify you) and never asks for student numbers. Start at the [feedback templates](https://github.com/MQ-EdTech/.github/issues/new/choose).

**Staff** — interested in using one of these tools in your unit, or have an idea for a new one? Open an issue on the relevant repo, or email **Aaron Chakerian** at [aaron.chakerian@mq.edu.au](mailto:aaron.chakerian@mq.edu.au).

**External developers** — the APA 7 Reference Checker is open source. Issues and PRs welcome.

## About
